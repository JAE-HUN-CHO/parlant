# Parlant에 기여하기

우리는 Linux 표준 개발자 증명서(DCO, [DCO.md](https://github.com/emcie-co/parlant/blob/develop/DCO.md))를 사용하므로, 기여함으로써 Apache 2.0 라이선스 하에 기여를 제출할 권리가 있음을 확인합니다 (즉, 기여하는 코드는 진정으로 프로젝트와 공유할 수 있는 코드입니다).

더 자세한 내용은 [CONTRIBUTING.md](https://github.com/emcie-co/parlant/blob/develop/CONTRIBUTING.md)를 참조하세요.

지금 바로 참여를 시작하고 싶으신가요? [Discord](https://discord.gg/duxWqxKk6J)에 참여하여 Parlant를 형성하는 데 어떻게 도움을 줄 수 있는지 논의해 봅시다. 공식 프로세스를 설정하는 동안 기여자들과 직접 협력하는 것을 기대합니다.

그렇지 않으면, [GitHub](https://github.com/emcie-co/parlant)에서 토론을 시작하거나 이슈를 열어주세요.
